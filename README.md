# Expense & Budget Visualizer

A mobile-friendly web application built for daily expense tracking, budget management, and visual spending analysis. Developed as part of the Coding Camp mini project.

## Features
- **Total Balance Tracking**: Automatically updates current balance when items are added or deleted.
- **Transaction Input Form**: Validates and records items with name, amount, and category (Food, Transport, Fun, and custom categories).
- **Interactive Transaction List**: Scrollable history with delete functionality and multiple sorting options (by amount or category).
- **Visual Chart**: Pie chart powered by Chart.js representing spending distribution by category.
- **Dark/Light Mode**: Toggle between themes for comfortable viewing.
- **Client-Side Storage**: Persists all data securely using the browser's Local Storage API.

## Tech Stack
- **HTML5** for structure
- **CSS3** for styling and theming
- **Vanilla JavaScript** (ES6+) for core logic and DOM manipulation
- **Chart.js** for data visualization

## Installation & Running Locally
1. Clone or download this repository.
2. Open `index.html` directly in any modern web browser (Chrome, Firefox, Edge, Safari) or use a local server extension like Live Server in VS Code/Kiro IDE.
